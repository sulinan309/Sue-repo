# 知识获取渠道

## 目标

让知识库持续获得可追溯的新知识，同时控制来源质量、案例泛化和重复内容。渠道负责发现候选知识，知识卡仍需经过证据分级、结构化写入和专家复核。

## 固定渠道

| 渠道 | 主要内容 | 建议频率 | 准入条件 | 进入知识库的结果 |
| --- | --- | --- | --- | --- |
| PubMed | 攀岩生物力学、运动学习、表现、心理和损伤研究 | 每月 | 同行评议；研究对象和任务与攀岩相关；摘要或全文可核查 | 来源记录、一般原理、证据边界 |
| PubMed Central | 可阅读全文的攀岩与运动分析研究 | 每月 | 全文可追溯；方法和结果能支持具体字段 | 原理卡、观察指标、评测方法 |
| BMC 等权威攀岩机构 | 动作教学、安全、教练体系和实践视频 | 每月 | 机构身份明确；材料仍可访问；适用对象清楚 | 教学顺序、练习设计、术语候选 |
| 岩馆标准 Beta | 当前线路、手脚顺序、身体朝向和替代解法 | 每次换线 | 岩馆、线路版本、难度和发布时间可确认 | 线路知识、E3 Beta 推断、评测片段 |
| 真人攀岩专家 | 定线、教练经验、术语和安全边界 | 每三张新卡或重大修订 | 记录专家身份、经验范围、日期和原始批注 | 专家复核、适用条件、反例 |
| 用户案例 | 卡点、提示、再次尝试和真实结果 | 每轮轻验证 | 视频授权和线路能够追溯；前后尝试可比较 | 案例卡、提示效果、易误判样本 |

## 固定检索主题

### 技巧与运动科学

- rock climbing / sport climbing / bouldering；
- biomechanics / kinematics / center of mass / equilibrium；
- motor learning / skill acquisition / video feedback；
- foot contact / postural adjustment / force transfer；
- movement fluency / route preview / visual search。

### 模型与视频分析

- pose estimation / motion reconstruction / action quality assessment；
- human-scene interaction / contact detection / climbing motion；
- monocular video / global trajectory / wall coordinate system。

### 安全与长期参与

- climbing injury / overuse / workload / recovery；
- fear of falling / self-efficacy / motivation / flow。

## 来源状态

候选来源依次经过：

> **发现 → 去重 → 登记 → 提炼 → 写入知识单元 → 专家复核 → 可试用**

- 仅有标题或二手摘要：保持“候选”；
- 摘要、全文或官方材料已核查：可以“登记”；
- 明确支持知识卡字段：标记“已使用”；
- 专家确认适用范围：标记“已复核”；
- 链接失效、研究被撤回或结论被更强证据取代：标记“已停用”。

## 每轮主动扩充流程

1. 检查知识分类和任务看板，选择一个对 MVP 有直接价值的缺口；
2. 检索至少一个研究来源与一个权威实践来源；没有直接研究时，明确证据缺口；
3. 先写动作意图、视频事实和观察边界，再写候选解释；
4. 新建或修订知识卡、来源、关系、场景和评测项；
5. 运行 JSONL、CSV、链接和标识符校验；
6. 在主动扩充路线图记录下一主题和待专家问题。

## 禁止自动升级的情况

- 单个教学视频中的口令；
- 单条线路的标准 Beta；
- 无法核实作者或出处的社交媒体内容；
- 普通视频推断出的真实力值、承重比例或唯一因果；
- 涉及疼痛、损伤和高风险动作的个人化判断。
