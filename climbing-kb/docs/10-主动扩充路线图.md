# 主动扩充路线图

**更新日期**：2026-08-29（A1 轮完成后）

## 选择标准

主动扩充优先考虑四项：

1. 新玩家在线路中出现的频率；
2. 对“怎么学、怎么解、怎么突破”是否有直接帮助；
3. 普通视频能否观察到关键时序；
4. 能否连接标准 Beta、用户视频和下一次行动。

## 现有知识加固顺序

1. 为精准踩点、重心转移和侧身补标准 Beta 与用户前后案例；
2. 把“主支撑脚—受力交接—动作意图”加入所有相关卡的观察字段；
3. 为折膝、动态和高脚补墙角、膝髋与落区安全边界；
4. 建立成功、失败、替代 Beta、遮挡和易误判的评测样本矩阵。

## 每轮最低交付

- 一张新卡或一张重要修订卡；
- 至少两个可追溯来源，其中至少一个为研究或权威机构；
- 三个线路场景；
- 一个物理示例；
- 一组视频观察字段；
- 一个现实任务和一个安全边界；
- 结构化索引、关系和版本同步；
- 明确的待专家问题。

   本轮所有外部来源只核到搜索返回的二手摘要，按 `docs/09` 的阶梯**全部停在「候选」**。
   因此 `TEC-CON-SWAP-003` 标 `专家共识` 而不是 `研究证据`。
2. **没有找到直接研究「换脚」的文献。** 最接近的三篇研究的都是「释放一只脚」，
   只覆盖换脚的前半段。缺口逐条写在
   [来源检索记录](../sources/2026-08-换脚与支撑交接-来源检索.md)。
3. **素材里没有一次同点换脚。** 实测两段素材里脚与岩点的关联率是 0，
   管线分不出「同点换脚」「换到另一个点」「脚脱落」——见 `CASE-2608-003`。
   这不是参数问题，是素材与感知能力的问题。

**待专家问题**：7 条，见 [待专家问题.md](../待专家问题.md)（Q-A1-01 … Q-A1-07）。

## 下一主题

进入 **A2｜手点方向与身体对抗**。重点回答：用户抓住同一个岩点时，
手的施力方向和脚下对抗如何改变身体的移动意图；普通视频能观察到什么，
哪些仍需线路信息或额外视角。

A1 轮暴露的两条经验，A2 开始前先处理：

- **先确认来源拿不拿得到，再决定写到什么强度。** A1 是写到一半才发现
  外部来源全部打不开。A2 的第一步应当是检索并登记来源，
  拿不到就提前把目标从「研究证据」下调到「专家共识 + 明确缺口」。
- **先问管线能不能看见，再写 observables。** A1 写了一条
  「新脚是不是落回旧脚那个点」，实测发现脚—岩点关联率为 0。
  这条仍然保留在卡里（它是需求，不是承诺），但已标进能力映射的 `hard` 名单。
  A2 涉及的「手的施力方向」很可能同样看不见，**要在写卡之前先量一次**。
