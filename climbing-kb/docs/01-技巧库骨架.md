对应《攀岩知识库｜框架与建设思路 v0.1》第 05 章。本文件是技巧库的地图。

## 01｜双轴结构

技巧库同时保留两条轴。两条轴在**技巧单元**上交汇——
同一个单元，从上面进来是「原理怎么落到动作」，从下面进来是「问题怎么找到解法」。

### 轴一：从原理到动作

```
物理原理（8 个）  →  底层动作原则（5 个）  →  具体技巧（10 个）  →  手脚接触方式
```

### 轴二：从问题到行动

```
用户的一句话  →  卡点（16 个）  →  多个候选解释  →  局部提示  →  现实任务（18 个）
```

轴二是产品实际走的路径。用户不会说「我力矩失衡」，他会说「我一松手就被转开」。
所以**卡点单元是产品的入口**，技巧单元是它的解释层。

用 `tools/query.py` 可以直接走一遍轴二：

```bash
python3 tools/query.py 脚滑
python3 tools/query.py --chain FAULT-FOOT-SLIP-001
```

## 02｜五个底层动作原则

来自 2026 年攀岩生物力学系统化研究，作为技巧库的科学骨架。

| 原则 | 攀岩中的含义 | 主要物理基础 |
| --- | --- | --- |
| [PRIN-CONTACT-001](../kb/principles/PRIN-CONTACT-001.md) 优化墙面接触 | 手脚以合适方向接触并加载岩点 | 摩擦、法向力 |
| [PRIN-STABLE-002](../kb/principles/PRIN-STABLE-002.md) 保持稳定 | 让各接触点形成可控的受力平衡 | 力平衡、力矩 |
| [PRIN-COM-003](../kb/principles/PRIN-COM-003.md) 移动重心 | 释放接触点前把身体移到可支撑的位置 | 重心投影、力臂 |
| [PRIN-LEGS-004](../kb/principles/PRIN-LEGS-004.md) 由腿部启动 | 主要位移优先由腿与髋产生 | 力量传递、动作链 |
| [PRIN-SPEED-005](../kb/principles/PRIN-SPEED-005.md) 选择合适速度 | 根据距离和岩点选择静态或动态 | 动量、冲量 |

**接触优化是另外四个的前提。** 重心移不过去，常常不是因为不知道要移，
而是因为脚没踩住、不敢把重量交出去。产品给提示时应当优先检查接触问题。

## 03｜单次动作的三个阶段

每个技巧单元的 `phases` 字段都按这三段描述：

| 阶段 | 发生什么 |
| --- | --- |
| **准备** | 调整接触点、身体方向和重心 |
| **执行** | 移动手、脚或整个身体 |
| **稳定** | 建立新的受力平衡，为下一步做准备 |

这套分段对视频分析尤其重要：
**产品可以先判断用户在哪个阶段停住，再决定播放哪段标准 Beta、调用哪类技巧知识。**

停在准备阶段 → 读线或重心问题；停在执行阶段 → 发力或时机问题；
停在稳定阶段 → 张力或配平问题。

## 04｜技巧库六层与首批十个主题

| 层 | 缩写 | 首批覆盖 |
| --- | --- | --- |
| 感知与决策 | `PER` | 读线与动作排序 |
| 底层动作原则 | — | 见上，用 `PRIN` 单独编号 |
| 身体位置 | `POS` | 重心转移、正身与侧身、身体张力与对抗 |
| 具体技巧 | `MOV` | 旗式、高脚与压脚站起、折膝 |
| 手脚组件 | `CON` | 精准踩点、脚点加载 |
| 动作策略 | `STR` | 静态、死点与动态 |

### 首批十个技巧

| 技巧 | 核心问题 | 主要物理 | 风险 |
| --- | --- | --- | --- |
| [TEC-PER-READ-001](../kb/techniques/TEC-PER-READ-001.md) 读线与动作排序 | 上墙前怎样看出手脚顺序 | 动作经济性 | 低 |

| [TEC-CON-LOAD-002](../kb/techniques/TEC-CON-LOAD-002.md) 脚点加载 | 踩到了为什么还是滑/站不起来 | 法向力、对抗 | 低 |
| [TEC-POS-COM-001](../kb/techniques/TEC-POS-COM-001.md) 重心转移 | 手已经很近却无法释放 | 重心、支撑面 | 中 |
| [TEC-MOV-FLAG-001](../kb/techniques/TEC-MOV-FLAG-001.md) 旗式 | 怎样减少开门和身体旋转 | 力矩平衡 | 中 |
| [TEC-POS-ORIENT-002](../kb/techniques/TEC-POS-ORIENT-002.md) 正身与侧身 | 转髋何时省力、何时增加触及 | 力臂、身体朝向 | 中 |
| [TEC-MOV-ROCKOVER-002](../kb/techniques/TEC-MOV-ROCKOVER-002.md) 高脚与压脚站起 | 高脚以后怎样站起来 | 重心越过支撑点 | 中 |
| [TEC-POS-TENSION-003](../kb/techniques/TEC-POS-TENSION-003.md) 身体张力与对抗 | 陡墙上怎样保持手脚连接 | 对抗力、动作链 | 中 |
| [TEC-MOV-DROPKNEE-003](../kb/techniques/TEC-MOV-DROPKNEE-003.md) 折膝 | 怎样旋转缩短距离并稳定身体 | 骨盆旋转、对抗 | **高** |
| [TEC-MOV-TWIST-004](../kb/techniques/TEC-MOV-TWIST-004.md) 侧身出手 | 侧身该在什么时候转（时序，非姿势） | 动作链时序、力矩 | 中 |

**折膝和动态是首批里风险最高的两个。** 它们的 `safety` 字段明显长于其他单元，
产品在推送相关任务时，安全提示必须与动作要领同时输出，不能折叠或省略。

## 05｜八个物理原理

| 原理 | 简化表达 | 主要连接技巧 |
| --- | --- | --- |
| [PHY-GRAVITY-COM-001](../kb/physics/PHY-GRAVITY-COM-001.md) 重力与重心 | 身体重量可简化为作用在重心上的力 | 重心转移、旗式、站起、读线、踩点 |
| [PHY-EQUILIBRIUM-002](../kb/physics/PHY-EQUILIBRIUM-002.md) 静态平衡 | 力和力矩都平衡，身体才稳定 | 旗式、张力、重心转移、站起 |
| [PHY-TORQUE-003](../kb/physics/PHY-TORQUE-003.md) 力矩与力臂 | 力离转轴越远，转动效应越大 | 旗式、侧身、折膝、重心转移 |
| [PHY-FRICTION-004](../kb/physics/PHY-FRICTION-004.md) 摩擦与法向力 | 摩擦上限取决于压紧程度和材料 | 精准踩点、脚点加载 |
| [PHY-OPPOSITION-005](../kb/physics/PHY-OPPOSITION-005.md) 对抗力与身体张力 | 相反方向的力互相压紧接触点 | 张力、折膝、脚点加载、侧身 |
| [PHY-KCHAIN-006](../kb/physics/PHY-KCHAIN-006.md) 动作链与力量传递 | 腿的力要经躯干才能传到手 | 站起、张力、动态、脚点加载、折膝 |
| [PHY-MOMENTUM-007](../kb/physics/PHY-MOMENTUM-007.md) 动量与冲量 | 速度和作用时间改变运动状态 | 死点、动态、张力 |
| [PHY-ECONOMY-008](../kb/physics/PHY-ECONOMY-008.md) 功、功率与动作经济性 | 同一线路可以有很不同的能量代价 | 读线、速度选择、侧身 |

### 物理表达的三条硬规则

1. **公式解释关系，不生成人体数值。** 可以说「髋离墙越远手越累」，
   不能说「你的重心偏离了 12 厘米」或「落点冲击力是 380 牛」。
2. **简化假设必须写出来。** 把人体近似为刚体或质点是有代价的，
   每个物理单元的 `model_assumptions` 字段记录这些代价。
3. **区分「物理上可能」和「对当前用户最适合」。** 前者是原理，后者需要身体条件数据，
   首期没有依据，不输出。

## 06｜卡点与任务

16 个卡点是产品的自然语言入口，18 个任务是知识落回岩馆的出口。

**卡点的硬规则**：每个卡点必须给至少 2 个候选解释，各自标明需要什么证据才能成立。
`tools/validate.py` 强制这一条——单一原因的卡点单元不予通过。

这条规则的意义在 `FAULT-DYNO-CATCH-009`（动态抓到了但没抓住）上最明显：
同一个「没抓住」，有五种机制，解法完全不同。
把它们合成一句「多练握力」，用户练很久也不会好。

**任务的硬规则**：`evidence` 字段必须是产品能从视频或用户确认里拿到的东西。
「感觉更稳了」不是证据，「伸手时脚有没有掉」是。

## 07｜下一批扩展

首批十个主题跑通后，按这个顺序扩展：

1. **换脚、换手** —— 高频且是很多卡点的前置条件
2. **脚跟钩、脚尖钩** —— 陡墙必需，物理上是对抗力的延伸
3. **抹蹭（smear）** —— 摩擦原理的直接应用，板墙核心技巧
4. **背旗、横向动态** —— 现有旗式和速度单元的自然扩展
5. **协调类动作** —— 需要动量单元支撑，难度较高
6. **不同墙面专项** —— 板墙、直墙、仰角、屋檐的专门解法

力量、心理、安全三个领域沿用同一套单元模板和证据体系，
不需要改动 `tools/` 下的任何脚本。
