### 一条被研究改掉的产品结论

Noé 2006 说：直墙上释放一条腿之前有预期性姿势调整，**仰角上没有**。
所以「视频里没看到重心先移动」**不能**当作判错依据——仰角上本来就可能看不到。
这条已经写进技巧卡的场景三，也写进了 `TASK-FOOT-TAP-021` 的适用范围
（先只限直墙和板墙）。

### 评测集：第一个易误判样本落库

`CASE-2608-003` 的 `measured` 全部来自管线，一条命令可复现：

```bash
python3 climbing-kb/tools/swap_segments.py annotator/out7   # qa/fixtures/out7 同样能跑
```

它取回了两段被检测器过滤掉的「脚离点段」：左脚各离开 0.43 秒，
两段肘角分别是 108.3° 和 92.5°（都弯着），但**重心分别上升 +0.087 和 +0.173 倍躯干长**。
只看肘角会报出「挂在手上」，那是错的——**系统在这两段上保持沉默才算对**。

同一份数据还给出了 A1 的硬边界：两段的移动脚相对另一侧踝净位移 0.32 / 0.97 倍躯干长，
**都不是同点换脚**；而全片脚与岩点的关联率是 **0**（左脚 0/29、右脚 0/77 接触帧，
另一段素材 `out5` 是 0/199 与 1/210），手是 19/20 与 69/70。
